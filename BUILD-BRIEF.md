# Build brief: Mart Laanpere personal academic + EdTech portfolio

## 1. Goal

Build a working visual prototype of my personal website using **al-folio + GitHub Pages**.

GitHub account: `martlaa`

Create a separate prototype repository, preferably:

`martlaanpere-site`

Do NOT overwrite an existing `martlaa.github.io` repository without asking first.

The site should combine four identities that conventional academic homepages usually keep separate:

1. academic researcher and professor;
2. mathematics and computing teacher educator;
3. EdTech designer/developer;
4. provider of research-based knowledge services and international expertise.

The central positioning is:

**RESEARCH · DESIGN · IMPACT**

The site should feel like a contemporary academic/EdTech portfolio, not merely an online CV.

---

# 2. Technical foundation

Use the current stable **al-folio** template.

Requirements:

- GitHub Pages deployment;
- GitHub Actions build/deployment;
- responsive desktop/tablet/mobile design;
- content mainly in Markdown/YAML/BibTeX;
- English first;
- architecture prepared for Estonian (`ET`) content later;
- publications stored in BibTeX or another structured source;
- projects/work represented as reusable collections;
- keep custom CSS/components reasonably separate from upstream al-folio so that future upgrades remain feasible.

Do not purchase or configure a custom domain yet.

# 3. Design references

Reference:

https://saguileran.github.io/

Especially inspect:

- homepage;
- Projects;
- Bio;

What I like:

- clean and approachable academic identity;

- restrained visual design;

## Mayank Mittal example

Use the specific academic al-folio Mayank Mittal example identified in the preceding ChatGPT conversation as visual inspiration.

What I particularly liked was the polished presentation of academic outputs and the visual treatment of publications/projects.

Do not blindly use search results for other people called Mayank Mittal.

## Overall combination

Take:

- Novoa's personal/project-oriented structure;
- Mittal's polished research/publication presentation;
- al-folio's underlying academic machinery;

and turn these into a more distinctive **academic + EdTech design portfolio**.

---

# 4. Visual language

Aim for:

**Nordic editorial design + subtle technology cues**

Avoid looking like either:

- a university departmental website; or
- an aggressive SaaS/startup landing page.

Preferred characteristics:

- generous white space;
- warm off-white/light background rather than sterile pure white if practical;
- near-black typography;
- one restrained deep blue/teal primary accent;
- perhaps one warm secondary accent such as ochre/yellow;
- strong typography;
- large project screenshots;
- subtle card borders/shadows;
- minimal animation;
- excellent readability.

Consider a strong serif for major headings combined with a modern sans-serif for UI/body text, provided this integrates cleanly with al-folio.

Avoid:

- animated backgrounds;
- skill percentage bars;
- rotating carousels;
- excessive gradients;
- giant social icons;
- startup clichés;
- “Hi, I'm Mart 👋”;
- excessive rounded cards everywhere.

The overall impression should be:

**experienced academic + designer + educational innovator**.
